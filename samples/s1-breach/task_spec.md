# Task Spec — AgentCourt Scenario 1 (Material Breach)

Contract: build a single-page product site for "NovaCart".
All clauses below are objective acceptance criteria.

## Clauses

1. The page must contain exactly five sections: `hero`, `features`,
   `pricing`, `testimonials`, `footer`.
2. The layout must be responsive at 375px, 768px and 1440px.
3. Lighthouse performance score must be ≥ 90.
4. All copy must be final English copy — no placeholder text.
5. The page must be publicly reachable over HTTPS.

## Compensation

850 GEN held in escrow. Full payment on meeting every clause.
Any missing clause is a material breach: full refund to the plaintiff.
